## Hi there 👋
My name is Lukas and I'm passionate about (bio)medical imaging and computer vision. Currently employed as a research associate at the University of Applied Sciences Upper Austrian Campus Wels. Researching and developing image enhancement methods to improve the resolution of micro-CT scans.

🔭 Currently working on [vIQA](https://github.com/3dct/vIQA), a python package for volumetric image quality assessment.

---

Projects I have worked on:
- [MA-Thesis](https://pure.fh-ooe.at/en/studentTheses/super-resolution-of-computed-tomography-images-using-3d-machine-l/): My master thesis on 3D-based super-resolution of trabecular bones.
- [BA-Code](https://github.com/Nepelius/BA_Nepelius): My bachelor thesis code on classifying and tracking wildlife animals.
- [Cloud Computing study project](https://github.com/Nepelius/clc3-Grp7): A study project on monitoring a note taking app with Grafana and Prometheus.
